# Task / Result Packet

## Task

**Название:** Цветовые состояния звеньев и удаление служебных подписей упражнения

**Владелец:** Стефания (`/root`); `review_integration_contract` — read-only review; `build_editorial_exercise` — адаптация существующих Storybook-проверок.

**Статус:** done

**Цель:** Отличить текущий, отвеченный и неотвеченный шаги цветом; удалить из UI квадраты, подписи «Ответ выбран/не выбран», счётчик заполненности и весь нижний динамический hint. Это оформление существующего упражнения, не оценка правильности.

**Источники:** [AGENTS.md](../../AGENTS.md), [PROJECT_STATE.md](../PROJECT_STATE.md), [WORKBOARD.md](../WORKBOARD.md), [контракт](../../docs/EDITORIAL_V2.md#упражнение-l01-s01), [активный мобильный эксперимент](2026-08-30-editorial-exercise-flat-mobile-experiment.md), текущая просьба и скриншот владельца от 2026-08-30.

**Write set:**

- `src/apps/editorial-v2/components/EditorialExercise/EditorialExercise.tsx`;
- `src/apps/editorial-v2/components/EditorialExercise/EditorialExercise.module.css`;
- `src/apps/editorial-v2/components/EditorialExercise/EditorialExercise.stories.tsx` — отдельный писатель `build_editorial_exercise`;
- `docs/EDITORIAL_V2.md`;
- этот task packet.

**Вне scope:** модель ответов/тексты вопросов/канонический content, сроки жизни state, маршруты, шапки/картинки, соседние Section, архив, общие токены, backend/storage/аналитика, зависимости, commit/push/publication. Мобильный список без рамок остаётся экспериментом, не объявляется окончательно выбранным.

**Исполнение:**

- Текущий пункт имеет приоритет активного оформления; отвеченный неактивный — спокойный тёплый фон, неотвеченный — исходный нейтральный фон. Заполненный номер слегка плотнее, чтобы отличие не сводилось только к цвету, без нового значка.
- Подписи заполненности и квадрат удаляются из видимой разметки, а `aria-label` кнопок сохраняет состояние для скринридера. `aria-current` и клавиатурный фокус остаются.
- Счётчик «Заполнено N из 9» удаляется; существующий номер текущего вопроса `01 / 09` остаётся, его удаление не запрошено.
- Весь нижний hint удаляется, включая сообщение о полной цепочке. Ссылка fieldset на него убирается; методическая оговорка у эмоции/импульса сохраняет собственную доступную связь.
- Вводный текст, добровольное чтение, инструкция о времени жизни ответов и все управляющие кнопки остаются. Правила выбора, пропуска, сверки и сброса не меняются.

**Риски:** путаница отвеченного шага с правильным ответом, потеря доступного имени/описания, схлопывание нужного интервала перед кнопками, устаревшие проверки счётчика. Цвет означает только наличие выбора; проверки опираются на состояние настоящих controls.

**План проверки:** реальный Browser/IAB с тремя состояниями сразу, mobile/desktop, выбор/перевыбор/возврат/сброс/сверка; отсутствие удалённых видимых подписей; корректность aria-describedby; существующие Storybook play и axe, сборки, ссылки/diff/baseline.

## Result

**Итог:** три состояния применены к навигации упражнения L01-S01 в mobile и desktop. Текущий пункт сохраняет холодный акцент и активное выделение, отвеченный неактивный имеет тёплый нейтральный фон; заполненный номер плотнее независимо от правильности выбора. Все запрошенные видимые статусы, квадрат, счётчик и нижний hint удалены. Доступные имена, native radio, методические оговорки и логика упражнения сохранены.

**Файлы:** только пять файлов write set. В Stories проверки удалённого счётчика заменены проверками реальных состояний навигации; добавлен пример `ThreeStepStates` с намеренно неверным первым ответом. Документирован смысл цветов без изменения продуктового scope или утверждения предыдущего мобильного эксперимента.

**Фактические проверки:**

- `npm run build` и статическая сборка Storybook — PASS. Существующее предупреждение о размере bundle остаётся; архитектура и зависимости не менялись.
- IAB, рабочий маршрут второго экрана: выбор/перевыбор, активный отвеченный пункт, возврат к прежнему выбору, сброс; тёплый фон у отвеченного неактивного, холодный у текущего, исходный у неотвеченного. Проверено сохранение ответов и открытого вопроса при переходе к истории и обратно, чтение всех девяти звеньев без упражнения, свободный переход к следующей истории и очистка состояния после выхода из Section.
- Ширины 320, 390, 554 и 1280 px: переполнения страницы нет; минимум высоты пункта навигации 72 px на mobile и 59 px на desktop. Удалённые подписи отсутствуют в видимом тексте, `aria-describedby` не содержит отсутствующих адресатов. Снимок трёх состояний: `/tmp/prozhito-exercise-step-states-mobile.jpg`.
- В реальном браузере Storybook: `KeyboardControls`, `FullWrongChain`, `ReadWithoutAnswers`, `CompleteFromMiddle` — Pass. Полностью неверная цепочка принимается, сверка показывает девять исходных абзацев; исправление и сброс сохраняют согласованные правила. Клавиатурный сценарий Tab/Space/ArrowDown/Enter дополнительно повторён в iframe шириной 390 px — Pass.
- Axe на четырёх перечисленных сценариях и `ThreeStepStates`: 0 violations / 0 inconclusive при desktop-проверке. Мобильный повтор axe не завершился до закрытия тестовой вкладки, поэтому отдельный mobile axe-pass не заявляется. В консоли рабочего экрана нет errors/warnings.
- Read-only review: существенных замечаний нет. `git diff --check`, `git diff --cached --check`, whitespace всех пяти файлов и относительные ссылки — PASS. SHA-256 baseline подтвердил, что внутри editorial source, общих компонентов/экранов и content изменены только три объявленных файла компонента; новых файлов в этих деревьях нет.

Мобильная композиция без рамок остаётся пробой для оценки владельцем. Архив, соседние Section, тексты и продуктовые правила не менялись; commit, push и публикация не выполнялись.
