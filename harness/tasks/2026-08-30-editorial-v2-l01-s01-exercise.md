### Выбранный сценарий и полнота материала

- Читатель сначала читает прежнюю полную историю.
- На втором экране восстанавливает девять звеньев в фиксированном порядке: Ситуация → Эмоция → Импульс → Риск → Пауза → Осознание → Инструмент → Зрелое действие → Наблюдаемый результат.
- Все названия звеньев доступны в навигации (сбоку на desktop, горизонтальная лента на mobile). Одновременно открыт один вопрос с тремя взаимоисключающими вариантами; выбранность нейтральна и не обозначает правильность.
- Полный исходный абзац звена присутствует среди вариантов без пометки правильности. Другие два — уже существующие дистракторы о вымышленном сюжете. Текст остальных восьми звеньев не выводится одновременно, но их вопросы доступны через навигацию.
- Выбор не переводит автоматически дальше. «Следующее» требует текущий ответ; назад и прямой переход позволяют пересмотреть любой пункт.
- Оценка не показывается после каждого ответа. После всех девяти открывается общая сверка, принимающая в том числе полностью ошибочную цепочку.
- Сверка содержит девять строк по порядку: выбранный ответ, полный исходный абзац разбора, текстовый статус совпадения/различия, пояснение и методические оговорки. Весь исходный аналитический материал сохраняется без сокращения; правильная формулировка становится явно обозначенной только в сверке.
- Для текущей интеграции сверка заменяет рабочую область внутри того же `#/editorial-v2/section/l01-s01/analysis`, без третьего адреса, третьего экрана и лабораторных tabs.
- Архив и L01-S02/L01-S03 сохраняют последовательное чтение девяти звеньев.
