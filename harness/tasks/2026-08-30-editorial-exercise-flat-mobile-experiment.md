# Task / Result Packet

## Task

**Название:** Пробный мобильный список ответов без отдельных рамок

**Владелец:** Стефания (`/root`); `review_integration_contract` — read-only CSS/a11y review.

**Статус:** done

**Цель:** Проверить гипотезу владельца: ответы на всю ширину рабочей области без зазоров и замкнутых рамок, только одиночные разделители; пункты верхней ленты заполняют её высоту без внешнего padding и рамки текущего шага.

Это явно запрошенный **эксперимент, не утверждение нового дизайна**. Проба применяется только к мобильному представлению L01-S01 (до 48rem) на существующем втором экране. Desktop и механика решения 28 сохраняются.

**Источники:** [AGENTS.md](../../AGENTS.md), [PROJECT_STATE.md](../PROJECT_STATE.md), [WORKBOARD.md](../WORKBOARD.md), [контракт editorial_v2](../../docs/EDITORIAL_V2.md#упражнение-l01-s01), [предыдущая итерация](2026-08-30-editorial-exercise-mobile-polish.md); два приложенных владельцем скриншота от 2026-08-30 с мобильными ответами и лентой звеньев.

**Write set:**

- `src/apps/editorial-v2/components/EditorialExercise/EditorialExercise.module.css` — один отдельно обозначенный блок мобильного эксперимента в конце файла;
- `docs/EDITORIAL_V2.md` — только пометка об активной пробе без объявления её принятой;
- этот task packet.

**Вне scope:** тексты/TSX/state, шапки Section, desktop-дизайн, сверка/полное чтение, другие Section, архив, общие токены, маршруты, новые настройки/переключатели, зависимости, сеть/storage, commit/push/publication. Общий продуктовый контракт и приоритеты не меняются.

**Обратимость:** базовые CSS-правила сохранены без изменений. Удаление блока между `BEGIN MOBILE ROWS EXPERIMENT` и `END MOBILE ROWS EXPERIMENT` возвращает предыдущую композицию. Дополнительная копия до правки — `/tmp/prozhito-exercise-flat-before.css`. Новый route или глобальный вариант компонентов не вводится.

**Исполнение:**

- `.answers` компенсирует внутренний gutter панели; label имеет тот же отступ для текста, без изменения размера шрифта. Между ответами нет gap; у соседних строк один разделитель.
- Выбранный ответ имеет прежний фон и узкую боковую метку вместо рамки; это сохраняет признак помимо цвета и не двигает текст.
- `.rail` без внешнего padding/gap; кнопки растягиваются по высоте строки, активный шаг обозначен фоном и нижней линией.
- Native radio, `aria-current`, текст заполненности и горизонтальная прокрутка сохранены; клавиатурный фокус отображается внутри границ элемента, чтобы не обрезаться.

**Риски:** границы клика могут стать менее очевидны; selected/focus должны оставаться различимы; горизонтальный overflow на breakpoint; старые forced-colors-правила могут вернуть рамки. Итоговое эстетическое решение остаётся у владельца.

**План проверки:** Browser/IAB до/после, mobile 320/390/554px и breakpoint 768/769, desktop; клики по строкам, выбор/возврат/сверка; текущий девятый пункт после resize; существующий keyboard Storybook и axe; build, baseline и diff/link checks. Без новых тестов, повторяющих CSS.

## Result

**Итог:** Мобильный эксперимент готов на прежнем втором экране. Ответы образуют непрерывный список до краёв рабочей области, без промежутков и замкнутых рамок. Между соседями по одной линии; выбранный ответ отмечен фоном и боковой меткой 3px. Верхняя лента не имеет внешнего padding/gap, все пункты занимают одинаковую полную высоту; текущий пункт имеет нижнюю линию вместо рамки. Это проба для оценки владельцем, окончательный дизайн не выбран.

**Файлы:** ровно три файла объявленного write set. В CSS только добавлен завершающий блок с уникальными BEGIN/END-маркерами, старые правила побайтно сохранены. В `docs/EDITORIAL_V2.md` добавлено отдельное предупреждение о неутверждённой пробе; базовый согласованный контракт не переписан.
