**Файлы:**

- `docs/YANDEX_CLOUD_INFRASTRUCTURE_PROPOSAL.md` — создано предложение.
- `harness/tasks/2026-08-31-yandex-cloud-infrastructure-plan.md` — создан и завершён рабочий отчёт.
- PROJECT_STATE / WORKBOARD / DECISIONS не менялись: архитектура пока не принята. Существующие пользовательские правки сохранены.

**Проверки:**

- `git diff --check`, `git diff --cached --check` — PASS.
- `git diff --no-index --check /dev/null <новый файл>` для обоих файлов — PASS.
- Read-only проверка 7 относительных Markdown-ссылок предложения — PASS.
- Read-only запуск существующего parser для всех 22 Section — PASS: 6 уровней, распределение 3 / 4 / 4 / 4 / 4 / 3, два экрана и девять звеньев.
- Проверка карты — PASS: 48 внутренних действий.
- Арифметика оценки — PASS: 5 627,52 ₽/месяц compute одного выбранного хоста PostgreSQL; пример backend без free tier — 63,21 ₽.
- Папка, контейнеры и выбранные ревизии, PostgreSQL/host/presets, security group, registry, функции, таймер, список бакетов — read-only PASS через профиль `default`. Первичный NotFound другого профиля устранён; активный профиль не переключался.

- Runtime API, нагрузочное тестирование, restore backup, end-to-end работа развёрнутого FinPulse и совпадение его image с изученным commit — NOT RUN; это план и выборочная инвентаризация, не release-pass/security-аудит.

**Источники и даты:** 31 августа 2026 года. FinPulse исследован на commit `0faca9c59bc450f8bd2fd795e54342897e6f21d3`; параметры папки сверены непосредственно с Cloud API. Официальные ссылки на возможности и тарифы приведены рядом с тезисами в предложении.

**Оставшиеся риски:**

- Не согласованы бюджет, нагрузка, домен, допускаемые простои, роли и точный состав первого запуска.
- Передача Lockbox-секретов в Serverless Containers помечена Preview; нужна техническая проверка и согласование риска.
- Однохостовая БД допустима только как явно согласованный пилот без HA; полный расчёт SSD, backup, трафика и вспомогательных сервисов ещё нужен.
- Переход источника истины из Markdown в БД и добавление пользовательских данных требуют отдельного продуктового решения.

**Следующий шаг:** согласование плана владельцем, без автоматического внедрения.
