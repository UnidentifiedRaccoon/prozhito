# Task / Result Packet

## Task

**Название:** Упражнение без заголовка и навигация по нижнему краю панели

**Владелец:** Стефания (`/root`); `build_editorial_exercise` — только два файла Stories; `audit_header_navigation` — read-only review.

**Статус:** done — реализация и локальные проверки завершены; browser QA не выполнен

**Цель:** Убран видимый заголовок «Соберите цепочку решения», полное чтение доступно кнопкой после form. Нижний ряд навигации занимает всю ширину панели вопроса без внешних отступов, две кнопки по 50% на desktop/mobile.

**Источники:** последнее уточнение владельца от 30 августа 2026 года; [AGENTS.md](../../AGENTS.md), [PROJECT_STATE.md](../PROJECT_STATE.md), [редакционный контракт](../../docs/EDITORIAL_V2.md), [решение 28](../../docs/DECISIONS.md#редакционное-исключение-28).

**Write set:**

- `src/apps/editorial-v2/components/EditorialExercise/EditorialExercise.tsx`;
- `src/apps/editorial-v2/components/EditorialExercise/EditorialExercise.module.css`;
- `src/apps/editorial-v2/components/EditorialExercise/EditorialExercise.stories.tsx` — отдельный писатель;
- `src/apps/editorial-v2/screens/EditorialSolutionScreen/EditorialSolutionScreen.stories.tsx` — тот же отдельный писатель;
- `docs/EDITORIAL_V2.md`;
- `docs/DECISIONS.md` — локальное уточнение решения 28;
- этот packet.

**Вне scope:** история, обложка/колонка800, канонические тексты, другие Section, архив/лабы, модель и время жизни ответов, новое хранение/dependencies, commit/push/publication. Полнота чтения, доступность сверки после любых девяти ответов и ограничения последовательной навигации сохраняются.

**Решение:** секция упражнения получает собственное aria-label вместо ссылки на удалённый h2. Form идёт первым, кнопка «Прочитать разбор без упражнения» — после него, вне формы. Вопросная панель — flex-column; ряд действий занимает нижний край панели без бокового/нижнего padding, gap=0, две равные колонки. Внутренние отступы самих кнопок сохраняют удобную цель нажатия. Последний шаг показывает «Предыдущее / Перейти к сверке» по половине ширины; при редактировании полностью заполненной цепочки быстрый переход к сверке сохраняется полной строкой над парой «Предыдущее / Следующее». DOM и визуальный порядок совпадают. Никакого fixed/sticky footer поверх текста.

**Риски:** потеря доступного имени после удаления h2; устаревший Tab-порядок после переноса чтения; отступы мобильного override; сжатие fieldset/перекрытие длинных ответов; лишняя третья кнопка в двухколоночном ряду; обрезка focus ring.

**План проверки:** scoped diff и source review полной/неполной/последней цепочки; адаптация существующих keyboard/reading Stories без ослабления assertions; production/Storybook build, baseline/ссылки/whitespace. Предыдущий URL policy block браузера не обходится другим портом/браузером. Границы непроведённого browser QA указать явно.

## Result

**Итог:** видимый заголовок удалён; секция получила самостоятельное доступное имя, заголовки чтения/сверки и их focus-target сохранены. Кнопка полного чтения находится после form. Нижний ряд панели — две равные колонки без внешних отступов на всех ширинах; последняя пара и быстрый переход к сверке сохраняют прежние условия. Панель не использует фиксированное позиционирование, fieldset не сжимается. Клавиатурный контур кнопок направлен внутрь и контрастирует с обоими фонами; forced-colors использует Highlight.

**Файлы:** изменены только семь файлов write set. В двух Stories адаптированы существующие проверки нового Tab-порядка, пассивного текста и быстрого перехода к сверке; проверки полноты ответов не ослаблены. Документы описывают новое положение управления только для editorial_v2 L01-S01.

**Фактические проверки:**

- `npm run build` — PASS, включает typecheck; осталось прежнее предупреждение об общем chunk >500kB.
- `npm run build-storybook -- --output-dir /tmp/prozhito-bottom-actions-storybook` — PASS; это сборка, не выполнение play-функций.
- `git diff --check`, `git diff --cached --check`, отдельная проверка whitespace семи файлов и целей относительных Markdown-ссылок — PASS.
- Snapshot всех 234 файлов src/content до задачи: изменились только компонент TSX/CSS и два согласованных Stories. Модель, контент, архив, остальные Section и лаборатории неизменны.
- Независимый read-only review JSX/CSS: проверены первый/средний/последний шаг и заполненная цепочка при редактировании, доступное имя, порядок DOM, нижний padding обоих responsive-режимов и видимость клавиатурного контура. Существенных дефектов не найдено.

**Ограничения:** браузер ранее явно заблокировал локальный адрес политикой URL; обход другим портом/браузером не предпринимался. В этой итерации не выполнены визуальный desktop/mobile QA и Storybook play-функции. Source review и успешная сборка не называются полным пользовательским или release-pass. При прилегании ответов к footer две соседние тонкие границы могут визуально сложиться; это остаётся предметом визуального просмотра. Коммит, push и внешняя публикация не выполнялись.

**Следующий шаг:** визуальный просмотр владельцем [локального второго экрана](http://127.0.0.1:5173/prozhito/#/editorial-v2/section/l01-s01/analysis). Следующие Section автоматически не меняются.
