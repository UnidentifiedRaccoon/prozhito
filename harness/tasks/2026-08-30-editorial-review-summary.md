## Уточнение: пояснения и оставшийся статус

Владелец просит убрать «Совпадает с разбором» и выяснить, сколько существует пояснений на вопрос, как они зависят от выбора и нужны ли при совпадении. Write set остаётся прежним. Модель и тексты пояснений вне scope изменения: текущая общая строка review исследуется read-only. Итоговый счётчик не подтверждён и не внедряется.


**Результат продолжения:** статус совпадения и его неиспользуемые CSS-правила удалены. Existing Stories теперь требуют отсутствия обеих меток; проверки 9/8/0 пар, полного текста, пояснений и фокуса сохранены. Production/typecheck и Storybook build — PASS, прежнее предупреждение bundle >500kB остаётся. Whitespace/relative links и оба diff-check — PASS. Snapshot 234 файлов src/content подтверждает изменение только трёх source-файлов компонента; модель и тексты пояснений неизменны. Browser QA/play по-прежнему не выполнялись из-за URL policy block.

**Что установлено о пояснениях:** в модели ровно девять полей review — одно на звено. Поле не привязано к optionId; при review оно показывается для любого из трёх ответов, включая совпавший. В режиме вопроса и полном чтении отсутствует. Тексты заранее записаны, а не генерируются при прохождении; они адаптированы из exerciseLabContent. Лабораторный packet определяет функцию как «пояснение границы», интеграционный packet предусматривает перенос пояснений, но отдельный утверждённый стандарт одинаковой обратной связи для всех трёх исходов не найден. Канонические девять абзацев — отдельный обязательный материал.

**Оценка полезности:** общий комментарий напоминает опорный факт/причинность и ограничения истории, но иногда опровергает невыбранный ответ; при совпадении может повторять уже показанный канонический абзац. Пример: совпавший «Риск» получает комментарий об окончании подписки из другого варианта; «Эмоция» одновременно обсуждает перенос срока и компенсацию, хотя выбран только один вариант.

**Предложение, не реализация:** два адресных пояснения на вопрос — для каждого из двух вариантов, отличающихся от разбора; при совпадении отдельное пояснение не показывать. Это 18 текстов на девять звеньев, плюс прежние девять канонических абзацев, которые сохраняются целиком. Каждый текст объясняет одно конкретное расхождение и его основание в истории, без реакции на другой невыбранный вариант и без нового события/обещания навыка. Изменение требует отдельного решения по этой схеме и контентной проверки; сейчас оно не внедрено. Итоговый индикатор также не подтверждён.


**Последующее решение владельца:** «Переходим к этой схеме» подтверждает два адресных пояснения на вопрос и отсутствие пояснения при совпадении. Реализация и проверка всех 18 текстов — [отдельный packet](2026-08-30-editorial-option-feedback.md). Прежние пометки об ожидании решения по пояснениям выше — история обсуждения; действующее решение зафиксировано здесь. Индикатор количества совпадений этим ответом не подтверждён.
