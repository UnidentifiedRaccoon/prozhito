# Task / Result Packet

## Task

**Название:** Сверка без дублирования совпадений и мобильное сравнение до краёв

**Владелец:** Стефания (`/root`); `build_editorial_exercise` — только Stories компонента; `audit_header_navigation` — read-only review.

**Статус:** implemented; визуальная проверка ограничена политикой доступа браузера.

**Цель:** Совпавшее звено показывается одним полным абзацем; пара «Ваш выбор / В разборе» остаётся только для расхождений. Мобильная пара сравнения занимает всю ширину экрана без двойных боковых отступов.

**Источники:** просьба и мобильный скриншот владельца от 30 августа 2026; [AGENTS.md](../../AGENTS.md), [PROJECT_STATE.md](../PROJECT_STATE.md), [контракт](../../docs/EDITORIAL_V2.md#упражнение-l01-s01), [решение 28](../../docs/DECISIONS.md#редакционное-исключение-28).

**Write set:**

- `src/apps/editorial-v2/components/EditorialExercise/EditorialExercise.tsx`;
- `src/apps/editorial-v2/components/EditorialExercise/EditorialExercise.module.css`;
- `src/apps/editorial-v2/components/EditorialExercise/EditorialExercise.stories.tsx` — отдельный писатель;
- `docs/EDITORIAL_V2.md`;
- `docs/DECISIONS.md` — только уточнение локального решения 28;
- этот packet.

**Вне scope:** вопросы/варианты/модель состояния, шапки, первый экран, другие Section и архив; новые маршруты, данные/хранение/dependencies, commit/push/publication.

**Исполнение:** совпадение определяется прежним canonicalOptionId. Во всех девяти звеньях остаются заголовок, статус, полный канонический абзац, пояснение и методические оговорки. При совпадении общий текст выводится один раз без подписей двух одинаковых частей; при отличии сохраняются обе формулировки с прежними разными фонами. Полное чтение без упражнения не меняется. На mobile до 48rem сравнение становится одной колонкой до краёв экрана с одним внутренним gutter; заголовки/пояснения и совпадения остаются в колонке чтения. Desktop использует всю прежнюю ширину текстовой части сверки, без вторжения в колонку заголовков.

**Риски:** потерять исходный абзац/оговорку при схлопывании, нарушить редактирование смешанной цепочки, получить горизонтальное переполнение или неверный gutter в Storybook.

**План проверки:** совпавшая, полностью отличающаяся и смешанная сверка; девять исходных абзацев по одному, количество пар равно числу отличий, все пояснения/оговорки сохранены; чтение и редактирование; сборки и Stories, mobile/desktop если доступен браузер, baseline/diff/ссылки. Ранее браузерный инструмент заблокировал локальный адрес политикой URL; блокировка не обходится через другой порт/браузер. При сохранении ограничения явно указать границы QA.

## Result

**Итог:** при совпадении выводится один полный канонический абзац без повторяющихся подписей. При расхождении остаются обе формулировки с разными фонами. Мобильная пара занимает всю ширину экрана, текст сохраняет один внутренний отступ; desktop сохраняет две колонки. Заголовки, статусы, пояснения и методические оговорки сохранены. Чтение без упражнения и логика ответов не менялись.

**Файлы:** все шесть файлов из write set. В компоненте изменено условие вывода сравнения; в CSS — мобильное расположение пары; Stories дополнены проверками совпадений и смешанной цепочки. Документы уточняют только локальное представление сверки L01-S01.

**Выполненные проверки:**

- Локальный рендер компонента без браузера и сетевого сервера: полное совпадение, смешанная цепочка, все ответы отличаются, чтение без ответов — PASS. В каждом состоянии девять исходных абзацев выводятся по одному; количество пар равно количеству отличий; пояснения и оговорки сохранены, кнопки редактирования/возврата присутствуют. Проверка не подтверждает геометрию или работу кликов.
- `npm run build` и сборка Storybook — PASS. Сохраняется предупреждение сборщика о крупных общих chunks; оптимизация сборки вне этой задачи.
- Stories для совпадений, расхождений и редактирования смешанной цепочки обновлены и включены в сборку, но их браузерные play-сценарии в этой итерации не запускались.
- `git diff --check` и `git diff --cached --check` — PASS; 22 относительные ссылки в изменённых документах/packet ведут в существующие файлы.
- Сравнение SHA-256 с исходным состоянием 234 файлов `src/` и `content/`: изменены только три разрешённых файла EditorialExercise. Остальные Section, архив и исходные тексты не затронуты.
- Независимое статическое review JSX, CSS и документации — без замечаний.

**Ограничения:** инструмент браузера ранее заблокировал локальный URL политикой доступа. Ограничение не обходилось через другой порт, браузер или способ управления. Мобильная/desktop геометрия, отсутствие переполнения и интерактивный пользовательский путь после этой правки визуально не подтверждены; это не полный browser QA или release-pass.

**Следующий шаг:** оценить обновлённую сверку в локальной демоверсии. Повторить мобильную и desktop проверку, когда браузерный доступ станет доступен. Коммит, push и публикация не выполнялись.
