# Task / Result Packet

## Task

**Название:** Согласовать женский канон Саши во всей истории и 22 Section

**Владелец:** Codex

**Статус:** done

**Цель:** После явного решения владельца перевести все относящиеся к Саше гендерно маркированные формы на женский род во всех канонических и пользовательских текстах, сохранив имя «Саша», события, причинность, финансовые тезисы, границы Section и точное совпадение экранов истории с книгой.

**Входные источники:**

- решение владельца от 23 августа 2026 года: Саша — женщина, канонический текст разрешено согласовать с выбранным D-F visual anchor;
- `docs/PRODUCT.md`, `docs/DECISIONS.md`, `docs/CONTENT_MAP.md`;
- `content/story/book.md` как источник событий и причинности;
- `content/sections/level-*/section-[0-9][0-9]-*.md` как 22 пользовательские Section;
- `content/program/competency-action-map.md`, `docs/METHODOLOGY.md`, `docs/SECTION_CONTRACT.md`, `docs/SAFETY.md`;
- project skills `section-methodologist` и `financial-safety-reviewer`.

**Write set:**

- этот task packet;
- `content/story/book.md`;
- все 22 готовые `content/sections/level-*/section-[0-9][0-9]-*.md`;
- `docs/CONTENT_MAP.md`, `content/program/competency-action-map.md` только для найденных описаний Саши;
- `docs/DECISIONS.md`, `docs/DESIGN_SYSTEM.md` только для записи принятого канонического решения;
- `harness/PROJECT_STATE.md`, `harness/WORKBOARD.md`;
- предыдущие task packets о casting и `living_archive_v1` только для закрытия ранее записанного гендерного риска.

**Вне scope:**

- изменение имени «Саша», пола или реплик других персонажей;
- изменение событий, порядка сцен, эмоций, финансовых утверждений, результата, источников и safety-границ;
- изменение названий, числа, порядка и границ Section;
- изменение девятизвенных цепочек, кроме строго необходимых форм согласования с женским каноном Саши;
- новые ассеты, компоненты, функции приложения, backend, публикация или Git-операции.

**Риски:**

- механическая замена может затронуть другого мужского персонажа, обобщающее слово «человек» или цитату, где род относится не к Саше;
- одна пропущенная форма создаст видимый continuity defect между книгой, Section, анализом и D-F;
- свободная редактура под видом согласования рода может изменить смысл финансового кейса или усилить показанный результат;
- 22 Section должны остаться точными полными фрагментами книги после миграции.

**План проверки:**

- зафиксировать полный список гендерно маркированных упоминаний Саши до правки и разделить их от форм других персонажей;
- изменить книгу, затем синхронно обновить каждый соответствующий фрагмент и описание в 22 Section;
- выполнить word-level semantic audit: допустимы только род, местоимения и необходимое грамматическое согласование;
- проверить отсутствие оставшихся мужских местоимений/форм, относящихся к Саше, и отсутствие ошибочного изменения других персонажей;
- проверить точное совпадение каждого экрана истории с границей книги;
- проверить `6 / 22`, распределение `3 / 4 / 4 / 4 / 4 / 3`, два экрана, `22 × 9`, 48 действий и относительные ссылки;
- выполнить `npm run build`, `npm run build-storybook`, browser QA L01-S01 и несколько поздних Section;
- выполнить `git diff --check` и `git diff --cached --check`.
