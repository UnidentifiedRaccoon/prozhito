# Task / Result Packet

## Task

**Название:** Прокрутка мобильной ленты, разделители и удаление ручного сброса

**Владелец:** Стефания (`/root`); `build_editorial_exercise` — только Stories, `audit_header_navigation` — read-only review.

**Статус:** done

**Цель:** При переходе показать активный пункт мобильного меню и новый вопрос, скрыть полосу прокрутки без отключения свайпа, разделить пункты короткими линиями и убрать «Начать заново».

**Источники:** [AGENTS.md](../../AGENTS.md), [PROJECT_STATE.md](../PROJECT_STATE.md), [WORKBOARD.md](../WORKBOARD.md), [актуальный контракт](../../docs/EDITORIAL_V2.md#упражнение-l01-s01), [решение 28](../../docs/DECISIONS.md#редакционное-исключение-28), [предыдущая UI-итерация](2026-08-30-editorial-exercise-question-layout.md), просьба и скриншот владельца от 30 августа 2026 года.

**Write set:**

- `src/apps/editorial-v2/components/EditorialExercise/EditorialExercise.tsx`;
- `src/apps/editorial-v2/components/EditorialExercise/EditorialExercise.module.css`;
- `src/apps/editorial-v2/components/EditorialExercise/EditorialExercise.stories.tsx` — отдельный писатель;
- `docs/EDITORIAL_V2.md`;
- `docs/DECISIONS.md` — уточнение удаления ручного reset в локальном решении28;
- этот packet.

**Вне scope:** первый экран, шапки/лаборатории, другие Section и архив; содержание, полнота чтения/сверки, последовательный доступ, время жизни ответов, новые данные/storage/API/dependencies, commit/push/publication.

**Исполнение:**

- Лента уже мгновенно центрирует активный пункт; явный переход получает плавное горизонтальное центрирование. По вертикали на mobile показывается начало ленты вместе с вопросом, на desktop сохраняется якорь панели. Reduced motion отключает анимацию. Клик по уже текущему пункту использует то же поведение.
- Вход/возврат с истории и resize только центрируют ленту без анимации, не прокручивают страницу и не забирают фокус у шапки. ResizeObserver не должен перебивать анимацию первым callback без изменения ширины.
- `overflow-x:auto` и свайп остаются; скрывается только scrollbar. Между пунктами — короткий вертикальный штрих по центру, без полного бордера или лишних отступов, не перехватывающий pointer events.
- Ручной reset удаляется из упражнения и сверки вместе с handler/CSS. «Изменить ответы» сохраняется. Пустое состояние по-прежнему создаётся владельцем Section при выходе/перезагрузке; модель состояния не удаляется.

**Риски:** конкуренция scrollIntoView/ResizeObserver, скрытый активный пункт на краях ленты, потеря вертикального свайпа, анимация при reduced motion, старые обещания reset в docs/tests. Новых пользовательских состояний/маршрутов нет.

**План проверки:** mobile first/middle/last и назад, плавность/конечная геометрия, resize/route return/reduced motion, скрытый scrollbar при доступной прокрутке, отсутствие reset во всех представлениях; прежние browser plays чтения/сверки/доступа/клавиатуры; build, baseline, ссылки/diff.

## Result

**Итог:** реализовано в объявленных шести файлах. Явный переход центрирует активный пункт и показывает начало ленты с вопросом; при reduced motion используется `auto`. Полоса прокрутки скрыта только на mobile, короткие разделители не перехватывают события. Кнопка «Начать заново», handler и её отдельный CSS удалены из упражнения и сверки. Редактирование, последовательный доступ и срок жизни ответов сохранены; актуальный локальный контракт синхронизирован в документации.

**Фактические проверки:**

- Production build с TypeScript и отдельная Storybook-сборка — PASS. После параллельного изменения шапок production build повторён — PASS; остаётся прежнее предупреждение о chunk больше 500kB.
- Встроенный браузер: 320×740, 390×844 и resize 1280×900 → 390×844. Нет горизонтального переполнения страницы; активные первый, средний, последний пункты и возврат назад видимы. На последнем пункте достигнут корректный предел ленты `1266px`; при возврате к восьмому — `1185px`.
- Плавность наблюдалась по последовательным DOM-измерениям горизонтальной позиции; конечная геометрия проверена после завершения анимации. На 320px верх ленты после перехода — около24px; на более высоком экране прокрутка может упираться в низ документа, оставляя больше места над лентой. Фокус после перехода — `legend`.
- Scrollbar имеет `none`, горизонтальный overflow остаётся `auto`; разделитель24px, ширина1px, `pointer-events:none`. Минимальная измеренная высота кнопок «Предыдущее»/«Следующее» —44.8px. Физический touch/swipe не эмулировался.
- Пройден путь всех девяти ответов → сверка → редактирование: девять звеньев/ответов сохранены, ручного сброса нет. Возврат с истории сохраняет пятый вопрос и девять ответов, оставляет фокус на `main` и страницу наверху. Выход в L01-S02 и назад очищает ответы, возвращает первый вопрос и блокирует восемь будущих пунктов.
- Восемь абзацев истории и все девять исходных абзацев полного разбора совпадают с проверенным исходным материалом. В чтении кнопки сброса также нет.
- Browser plays `Keyboard Controls`, `Sequential Access`, `Full Wrong Chain`, `Read Without Answers`, `Complete From Middle` — PASS; для каждого desktop accessibility:0 violations/0 inconclusive. `Keyboard Controls` повторён в iframe реальной ширины390px — PASS.
