# Task / Result Packet

## Task

**Название:** Редакционная версия по умолчанию на облачном сайте.

**Владелец:** Стефания.

**Статус:** done

**Цель:** Открытие `https://prozhito.ncfg.ru/` сразу показывает существующую редакционную версию, сохраняя доступ к архиву и прямым ссылкам.

**Входные источники:** Запрос владельца от 31 августа 2026 года; `docs/PRODUCT.md`, решения 27 и 39, `harness/PROJECT_STATE.md`, текущий cloud entry и hash-router.

**Write set:** `src/apps/cloud/main.tsx`; этот packet; решение 40 в `docs/DECISIONS.md`; `docs/PRODUCT.md`, `harness/PROJECT_STATE.md`, `docs/operations/yandex-cloud-pilot.md`; новая cloud-сборка в существующем reader-бакете.

**Вне scope:** Тексты, иллюстрации, количество Section, механизм упражнения, админка, API/БД/расписание, GitHub Pages, коммит и push. Дневной stop/start БД по-прежнему не разрешён.

**Риски:** Не перехватить явный `#/` архива, `#/versions/` и глубокие ссылки; не добавить промежуточный архивный экран или лишнюю запись истории браузера. Редакционная версия пока содержит только три существующие Section.

**План проверки:** Сборка cloud и типизация; браузер: корень → редакционный каталог → история → назад в каталог; явный вход в архив через выбор версий; перезагрузка и прямая ссылка; ошибки консоли; `git diff --check` и ссылки документов.

## Result

**Итог:** Опубликовано на `https://prozhito.ncfg.ru/`. Обычный вход сразу открывает `#/editorial-v2/` и каталог «Первый месяц». Явный `#/` сохранён для архива, `#/versions/` и обе версии доступны. Инициализация выполняется в cloud entry до монтирования React, без эффекта/промежуточного архивного рендера и дополнительного шага Back.

**Файлы:** Изменены только объявленные исходники и документы. В reader-бакет опубликованы JS/CSS и `cloud.html`; HTML на рабочем адресе полностью совпадает со сборкой. Старые хешированные assets сохранены. Админка, API, БД, расписание и GitHub Pages не выпускались; commit/push не выполнялся.

**Проверки:**

- `npm run build:cloud` — PASS, включая типизацию.
- Проверка реального блока инициализации в изолированном JS-контексте — 5/5 PASS: пустой hash, архив, выбор версий, редакционная и архивная глубокие ссылки. Query-параметры и history state сохранены, явные hash не переписываются.
- Рабочие HTML и все шесть JS/CSS-файлов — GET 200; HTML равен локальной сборке.
- Browser/IAB, 1280×720: корень → редакционный каталог → первая история → «Все истории» → каталог; перезагрузка сохраняет редакционную страницу. Выбор версий → «Архивная версия» открывает прежний `#/` и архивный экран.
- Browser/IAB, 390×844: обычный адрес снова открывает редакционный каталог; ширина документа 390px, без горизонтального переполнения. Снимок показан и визуально проверен. Заголовок страницы «Первый месяц — Прожито», содержимое непустое, framework overlay отсутствует, error/warn в консоли нет. Временная ширина браузера восстановлена.
- `git diff --check` и `git diff --cached --check` — PASS; 53 локальных адреса Markdown-ссылок существуют.

**Источники и даты:** Запрос владельца, локальные исходники и фактический ответ рабочего сайта, 31 августа 2026 года. Внешняя KB не настроена; использованы канонические проектные документы.

**Оставшиеся риски:** Проверены затронутые маршруты, не полный повторный QA всех 22 Section. Реальный stop/start рабочей БД не выполнялся и не относится к этой задаче.

**Следующий шаг:** Просмотр владельцем нового стартового входа; дальнейшее расширение редакционной версии — только по отдельному запросу.
