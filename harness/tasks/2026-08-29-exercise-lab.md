**Риски:**

- проверить три разные механики, возможность ошибиться и перейти к третьему экрану только после ответа;
- проверить точность результата: согласована и записана новая дата, платёж не показан;
- проверить отсутствие personal data, хранения, рекомендаций и сетевых вызовов;
- выполнить `npm run build` и `git diff --check`;
- проверить desktop и mobile в браузере: загрузка, console health, клавиатурный focus, минимум по одному неверному и верному ходу для каждого варианта.
