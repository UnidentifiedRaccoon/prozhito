# Task / Result Packet

## Task

**Название:** Сформировать пять концептов UI и дизайн-системы

**Владелец:** Codex (координатор консилиума)

**Статус:** done

**Цель:** Предложить пять системно различающихся визуальных направлений для мобильного content-first приложения «Прожито», сравнить их пригодность и выбрать направление для следующего прототипного шага.

**Входные источники:**

- `AGENTS.md`, `harness/PROJECT_STATE.md`;
- `docs/PRODUCT.md`, `docs/DECISIONS.md`, `docs/CONTENT_MAP.md`, `docs/DESIGN_SYSTEM.md`;
- текущие `src/styles/tokens.css`, `src/styles.css`, продуктовые и UI-компоненты;
- Pinterest-доска пользователя «Акварель»: `https://pin.it/3LXEsuuOm`;
- read-only заключения продуктового стратега, арт-директора и архитектора дизайн-системы.

**Write set:**

- только этот task packet.

**Вне scope:**

- изменение интерфейса, токенов, компонентов, контента и канонических решений;
- создание ассетов до выбора направления;
- Figma, код прототипа, новые зависимости, backend, API, хранение, аналитика и публикация;
- Git staging, commit и push.

**Риски:**

- декоративная акварель может снизить контраст и читаемость длинного текста;
- пять направлений могут оказаться цветовыми вариациями одной системы вместо разных концепций;
- финансовая тема может стать слишком «банковской», назидательной или инфантильной;
- визуальная метафора прогресса может противоречить отсутствию прогресса и геймификации;
- публичная Pinterest-доска содержит только четыре пина и ограничивает глубину референсного анализа.

**План проверки:**

- проверить каждое направление против структуры `6 / 22`, двух экранов и девятизвенной цепочки;
- проверить mobile-first, длинное чтение, контраст, focus и reduced motion;
- убедиться, что у каждого концепта различаются композиция, материал, типографика и грамматика ассетов, а не только палитра;
- сверить итог с текущей трёхслойной token-архитектурой и утверждённым `DecisionChain / Path`;
- выполнить `git diff --check` для task packet.

## Result

**Итог:** Сформированы и сравнены пять системно различных направлений: «Живой архив», «Маршрут нового города», «Стол решений», «Тихое кино» и «Спокойный конструктивизм». Консилиум рекомендует «Живой архив» как основу, дополнив её ограниченной акварельной пластикой референса, структурной линией маршрута и небольшим набором обезличенных предметных иллюстраций.

**Файлы:**

- `harness/tasks/2026-08-23-design-system-consilium.md`.

**Проверки:**

- product-fit против `6 / 22`, двух экранов, полного лонгрида и девятизвенного `DecisionChain / Path` — PASS;
- пять направлений различаются композицией, материалом, типографикой, motion и грамматикой ассетов — PASS;
- mobile-first, contrast/focus, reduced motion и отсутствие смысла только в цвете включены в общие guardrails — PASS;
- интерфейс, токены, компоненты и контент не изменялись — PASS;
- `git diff --check`, `git diff --cached --check` — PASS; отдельный no-index whitespace-check нового task packet не выявил ошибок.

**Источники и даты:**

- проектные `docs/PRODUCT.md`, `docs/DECISIONS.md`, `docs/CONTENT_MAP.md`, `docs/DESIGN_SYSTEM.md` и текущая клиентская реализация, проверено 23 августа 2026 года;
- публичная Pinterest-доска «Акварель» из четырёх пинов, раскрытая из `https://pin.it/3LXEsuuOm` в `https://ru.pinterest.com/yuraposledov/акварель/`, визуально проверена 23 августа 2026 года;
- read-only заключения продуктового стратега и архитектора дизайн-системы, синтезированы 23 августа 2026 года.

**Оставшиеся риски:**

- выбор концепта пока не подтверждён владельцем;
- финальные шрифты, палитра и стабильность генерации иллюстраций требуют проверки на одном design spike;
- публичная Pinterest-доска содержит только четыре пина, поэтому референс задаёт направление, но не полный визуальный контракт.

**Следующий шаг:**

- После выбора владельцем подготовить один честный design spike: каталог, длинный экран истории и полный девятизвенный разбор на ширинах `320 / 390 / 768 px`, а также небольшой starter asset kit выбранного направления.
