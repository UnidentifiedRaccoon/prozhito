# Task / Result Packet

## Task

**Название:** Удалить перечисленные вспомогательные подписи упражнения

**Владелец:** Стефания (`/root`); `build_editorial_exercise` — только Stories; `audit_header_navigation` — read-only аудит документов.

**Статус:** done — реализация и локальные проверки; browser QA ограничен доступом инструмента.

**Цель:** На втором экране editorial_v2 L01-S01 больше не показаны перечисленные владельцем вводные/lifetime подписи и три отдельные методические заметки. Вопросы, варианты, девять исходных абзацев и пояснения сверки сохранены.

**Источники:** точный список удаляемых текстов в последней просьбе владельца от 30 августа 2026 года; [AGENTS.md](../../AGENTS.md), [PROJECT_STATE.md](../PROJECT_STATE.md), [редакционный контракт](../../docs/EDITORIAL_V2.md), [решение 28](../../docs/DECISIONS.md#редакционное-исключение-28), [методология](../../docs/METHODOLOGY.md), [safety](../../docs/SAFETY.md).

**Удаляемые тексты:**

- «Выберите формулировку для каждого из девяти звеньев. После заполнения всей цепочки можно сверить ответы с разбором истории.»;
- «Все девять звеньев истории — без заполнения и оценки ответов.»;
- «Ответы остаются только пока вы в этой истории. После выхода из неё или перезагрузки они исчезнут.»;
- «Это методическая линза разбора, а не дословно названная Сашей эмоция.»;
- «Это причинная гипотеза разбора, а не дословно показанная мысль Саши.»;
- «Согласие Тамары — событие этой вымышленной истории, а не гарантия переноса срока в другой ситуации.».

**Write set:**

- `src/apps/editorial-v2/components/EditorialExercise/EditorialExercise.tsx`;
- `src/apps/editorial-v2/components/EditorialExercise/EditorialExercise.module.css`;
- `src/apps/editorial-v2/components/EditorialExercise/EditorialExercise.stories.tsx` — отдельный писатель;
- `src/apps/editorial-v2/model/editorialExercise.ts` — только удаление неиспользуемого поля methodNote и его трёх значений;
- `docs/EDITORIAL_V2.md`;
- `docs/DECISIONS.md` — локальное уточнение решения 28;
- `docs/METHODOLOGY.md` — только обещание UI-подписей в редакционном исключении;
- этот packet.

**Вне scope:** первый экран, обложка/колонка800, другие Section, архив и лаборатории; канонические тексты, вопросы/дистракторы/пояснения link.review, механика ответов и срок их жизни; навигация, backend/storage/dependencies, commit/push/publication.

**Решение:** удалить именно перечисленные отдельные тексты, не заменять их скрытыми дублями и не оставлять пустые абзацы. Не затрагивать вступление сверки «Сопоставьте свой выбор…», заголовки, кнопки чтения/возврата, статусы и объяснения. Удалить неиспользуемые lifetime/methodNote CSS и поле модели. Методические ограничения сохраняются в документации: эмоция/импульс остаются интерпретациями, случай Тамары не обобщается на другие ситуации. Срок жизни ответов остаётся прежним, хотя его подпись убрана.

**Риски:** случайно удалить исходный материал или пояснения сверки вместе с дополнительными заметками; оставить противоречащие текущему UI обещания в документации/Stories. Разрешение владельца касается видимых подписей, не расширения смысловых или продуктовых границ.

**План проверки:** scoped diff и baseline, синхронизация существующих Stories, production/Storybook build, ссылки/whitespace, read-only аудит документации. Новые тесты на обратимую чистку текста не добавляются. Browser URL ранее заблокирован политикой инструмента; ограничение не обходится другим портом или браузером, сборка не выдаётся за визуальное QA.

## Result

**Итог:** все шесть перечисленных текстов удалены из интерфейса. Упражнение и полный разбор открываются заголовком и кнопкой без прежних вводных абзацев; сверка сохраняет своё отдельное вступление. Три методические заметки больше не выводятся ни в чтении, ни в сверке; неиспользуемое поле модели и CSS удалены. Вопросы, варианты, девять исходных абзацев, link.review, статусы, кнопки и срок жизни ответов не менялись. Пустые абзацы и скрытые дубли не добавлены.

**Файлы:** восемь файлов write set. Stories адаптированы отдельным писателем только в разрешённом файле; существующие проверки полноты абзацев, объяснений и сценариев сохранены, новых тестов нет.

**Проверки:**

- Поиск перечисленных текстов, methodNote и lifetime в `src/apps/editorial-v2` — совпадений нет. JSX не оставляет пустой абзац полного чтения; вступление сверки выводится только в review.
- Production build с TypeScript и Storybook build — PASS. Прежнее предупреждение о крупных общих chunks сохраняется; оптимизация вне scope.
- Baseline 234 файлов `src/` и `content/` — PASS: изменены только четыре разрешённых source-файла. Исходный контент, прочие модели/экраны, обложки, колонка800, архив и лаборатории прежние. Scoped diff модели содержит только удаление methodNote, без изменений вопросов, вариантов или пояснений.
- `git diff --check`, `git diff --cached --check`, whitespace восьми файлов и 38 относительных ссылок — PASS.

**Оставшиеся риски:** новую плотность текста после удаления подписей нужно оценить визуально; интерактивный путь повторно не пройден из-за ограничения браузерного инструмента. Методические пределы и фактическая очистка ответов сохранены, но прежние отдельные пояснения больше не показываются читателю. Это локальное изменение, не полный release-pass.

**Следующий шаг:** оценить обновлённый второй экран в локальной демоверсии; при восстановлении разрешённого browser-доступа повторить визуальную проверку. Коммит, push и внешняя публикация не выполнялись.
