# Editorial v2

Изолированная редакционная версия статической демоверсии «Прожито».

## Граница

- Маршруты: `#/editorial-v2/` и первые три Section уровня 1.
- Выбор между версиями вынесен на `#/versions/`; внутри приложения нет сравнительной навигации или prototype-metadata.
- Общие с основной демоверсией данные: только проверенная коллекция Section и типы контентного контракта.
- Собственные: shell, компоненты, стили, изображения, экранные композиции и Storybook stories.
- Запрещены импорты из legacy `components`, `screens`, `styles`, `visuals` и `assets/living-archive`.
- Ровно два экрана: «История» и «Решение». По [решениям28/30](../../../docs/DECISIONS.md#упражнения-трёх-section-30) L01-S01–L01-S03 содержат на втором экране добровольное упражнение «Шаг за шагом», сверку и полный разбор без упражнения. Архив сохраняет чтение; лабораторная оболочка сюда не входит.
- Ответы живут только в памяти текущей Section при переходах «История ↔ Решение»; выход из Section или перезагрузка очищают их. Storage, сервер, прогресс и аналитика отсутствуют, следующая история всегда доступна. По [решению33](../../../docs/DECISIONS.md#цикл-section-33) ссылка продолжения замыкает маршрут S01 → S02 → S03 → S01 и открывает историю следующей Section. Новый круг начинается без прежних ответов; автоматических переходов нет, выход в каталог остаётся через обложку.
- Оба экрана открывает выбранный `EditorialCover`: белое название на тёмном градиенте внутри изображения и одна круглая стрелка в каталог. Повторный masthead и подписи типа экрана убраны; каталог сохраняет «Прожито».
- В L01-S01 используется утверждённая пара из лаборатории: Саша в комнате / календарь в телефоне. Календарный asset скопирован в production namespace; импорта из лаборатории нет. S02/S03 сохраняют существующие сюжетные изображения на обоих экранах.
- Типографика/crop/размеры обложки соответствуют J / `cover` — [решение29](../../../docs/DECISIONS.md#редакционная-обложка-29).
- Мобильный каталог до48rem включительно использует D «Номер на наплыве»: изображение сверху, светлый текстовый блок с наплывом32px, номер на подложке поднят на50% над его краем. Принятый crop ограничен каталогом; desktop и экраны Section не меняются. [Решение32](../../../docs/DECISIONS.md#мобильный-каталог-32).
