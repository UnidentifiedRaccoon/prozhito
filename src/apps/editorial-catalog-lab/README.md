# Лаборатория компактного каталога

Изолированная проба мобильных карточек трёх Section `editorial_v2`. Владелец утвердил D «Номер на наплыве»: он перенесён в мобильный рабочий каталог до48rem включительно по [решению32](../../../docs/DECISIONS.md#мобильный-каталог-32). Остальные пробы сохранены для сравнения.

## Просмотр

При работающей локальной разработке: `http://127.0.0.1:5173/prozhito/#/lab/editorial-catalog`.

| Адрес после `/prozhito/` | Композиция |
| --- | --- |
| `#/lab/editorial-catalog/original` | 0 — исходная мобильная анатомия: текст, затем большой кадр 3:2 |
| `#/lab/editorial-catalog/split` | A — текст слева, узкий кадр справа; вариант по умолчанию |
| `#/lab/editorial-catalog/background` | B — изображение справа плавно переходит в светлую подложку текста |
| `#/lab/editorial-catalog/overlap` | C — наплыв с номером вплотную к верхнему левому углу изображения |
| `#/lab/editorial-catalog/overlap-raised` | D — наплыв с номером, наполовину поднятым над верхней границей текстового поля |
| `#/lab/editorial-catalog/compare` | Все пять проб рядом либо друг под другом, если места недостаточно |

В C номер расположен без отступов от верхнего и левого края изображения. В D он выровнен по левому краю текста и поднят над границей наплыва на50% собственной высоты. В обоих вариантах сохранена небольшая непрозрачная светлая подложка без рамки и скругления; номер не занимает строку над заголовком и остаётся декоративной частью единой ссылки. Кадрирование и остальная геометрия наплыва одинаковы. Остальные композиции не меняются; C не утверждён, D принят для мобильного каталога.

Каждая проба содержит все три настоящие Section. Вся карточка — одна ссылка на историю; ссылка «К каталогу» открывает действующий редакционный каталог. Переключение вариантов работает через hash, поэтому можно передать адрес конкретной пробы и пользоваться историей браузера.

На desktop можно выбрать ширину пробы 320, 390 или 430px. На mobile поле растягивается на доступную ширину; desktop-переключатель скрыт. Ширина — временный React-state без сохранения. Типографика карточек зависит от контейнера пробы, а не от ширины desktop-окна. Это не эмулятор телефона: здесь нет масштабирования, iframe, панели устройства или подмены пользовательского агента.

## Граница реализации

- Новый lazy-маршрут и собственные компоненты/CSS Modules. В рабочий каталог не добавлены лабораторные ссылки или переключатели.
- Тексты и изображения берутся из `buildEditorialV2Program`; полные title/summary и реальные переходы сохранены, сокращения и обрезка строк не используются.
- Тема и шрифты — из `EditorialTheme`. Вариант0 «Исходный» сохраняет мобильную анатомию `EditorialChapterIndex` до принятия D: прямое использование production-компонента включило бы desktop-стили внутри узкой пробы на широком экране.
- Экспериментальное кадрирование задано локально; принятый crop D перенесён отдельно в мобильный каталог. Исходные иллюстрации и shared focal metadata не меняются. Под текстом B остаётся плотное бумажное поле, включая тёмную третью иллюстрацию.
- Новые изображения, зависимости, сервер, аналитика, ответы или хранение не добавлены. Сгенерированный композиционный эскиз использован только как черновой ориентир, не как приложение или новый сюжетный asset.
- Экран упражнения, шапки Section, архив и прежние лаборатории не изменяются. Принятие D и его проверки описаны в [packet переноса](../../../harness/tasks/2026-08-30-editorial-catalog-overlap-adoption.md).

## Проверка

Storybook: `Editorial v2 / Labs / Compact catalog` — исходная карточка, четыре компактные пробы, сравнение и узкий экран. Фактические результаты сборок и проверок записаны в [task/result packet](../../../harness/tasks/2026-08-30-editorial-catalog-lab.md).

Браузерная проверка в текущей сессии заблокирована URL-policy. Проверки React-разметки и сборки не подтверждают реальные переносы строк, crop, фокус и взаимодействие в браузере. После принятия D остаются просмотр рабочего каталога на телефоне и визуальный QA. Процент экономии высоты не заявляется: он зависит от Section и ширины.
